Scripts en python para descargar canciones con links de canales de youtube en su sección de videos, playlists de spotify (en teoría debe leer el nombre de la canción para buscarla en yt y descargarla). Leer csv con datos de las canciones.
Si quieren tener sus playlists de spotify y que lo pueda leer como csv, recomiendo esta página web: https://www.chosic.com/spotify-playlist-exporter/

Nota: No me hago responsable del uso irresponsable de esta herramienta. Tarquitet solamente la ha utilizado para explorar la velocidad de una descarga ya que aveces los navegadores se bugean con el 99% y es mucho tiempo de espera innecesaria.
